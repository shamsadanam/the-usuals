# docs

The docs site for docs.shamsad.com, built with Nuxt 4 + Nuxt Content.

Pages live in `content/`, one folder per stack (`content/nuxt/`, `content/next/`, ...).
The code they document lives in `../examples/<stack>`.

```bash
pnpm dev:docs   # from the repo root
```

## Vercel

- Root Directory: `docs`
- Framework preset: Nuxt.js
- Domain: `docs.shamsad.com`
